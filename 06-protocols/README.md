# 06 — Protocols

The working agreements of the houses:

- **UZAP** — Crystal's identity-recovery protocol; lives in its own public
  repository: https://github.com/crystalispsychotic/uzap-protocol
- **The Bridge rules** — originals stay home untouched; copies travel by
  hand, verbatim for rulings, numbers, and quotes; author first, carrier
  second, dated both ways; mirrors are never edited.
- **Branch format** — see the root README, "How to add a branch."
- **Ratification** — core-text changes are approved by a named human
  steward or a defined quorum. Silence is never approval, and no proposal
  executes itself.
