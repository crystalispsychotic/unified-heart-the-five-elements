# 03 — The Notebooks

Index shelf for Crystal's digitized spiral notebooks. The PDFs themselves
live at home in Google Drive (several are far over GitHub's 100 MB file
limit); each notebook appears here as an index line — title, page count,
where it lives, and whether it has been read.

A notebook's pages join this shelf only when Crystal names that notebook.
Read so far, in full: blueskull (61 pp), greenthoughts (41 pp),
whiteloose — read under the houses' ten-page rhythm, with the reader's
lanes kept separate from the author's words.
